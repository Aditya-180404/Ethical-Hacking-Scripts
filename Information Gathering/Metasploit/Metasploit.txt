## Metasploit

It is a powerful framework used for penetration testing, vulnerability assessment, and exploitation. Metasploit provides a wide range of tools and modules that allow security professionals to identify and exploit vulnerabilities in systems and applications. It includes features such as payload generation, exploit development, and post-exploitation capabilities.

By this we can do scanning, enumuration, payload creation,monitoring,clearing the track, attacking etc tasks.

Here we can use the inbuilt tools of metasploit also the tools like nmap, hping3 etc.


## Scripts

1. service start postgresql -> starts the postgresql , the database of the metasploit framework.
2. msfconsole -> starts the metasploit console.
3. db_status -> checks database connection.
4. exit
5. msfdb init -> creates and initialize the database.
6. service postgresql restart -> restarts the postgresql service.
7. msfconsole -q -> starts the metasploit console in quiet mode.
8. msfconsole 
9. db_status -> checks the status of the database connection. after successful connection it shows this prompt "[*] Connected to msf. Connection type: postgresql."
10. search <module_name> -> searches for a specific module in the Metasploit framework.
11. use <no_of_module> or use <module_name_with_path> -> loads a specific module for use.
12. show options -> displays the available options for the loaded module.
13. back -> returns to the previous menu or context in the Metasploit console.
14. hosts -o <path_to_file> -> saves the list of discovered hosts to a specified file.


## Internal Modules

# portscan module
1. search portscan -> searches for port scanning modules in the Metasploit framework.
2. use 6 -> loads the "auxiliary/scanner/portscan/syn" module for TCP port scanning.TCP SYN Port Scanner
3. show options -> displays the available options for the loaded module.
4. set RHOSTS <target_ip> -> sets the target IP address for scanning.
5. set THREADS <number_of_threads> -> sets the number of threads to use for scanning.
6. set PORTS <port_range> -> sets the range of ports to scan on the target system.
7. show options -> displays the available options for the loaded module.
8. run -> executes the loaded module with the specified options.
