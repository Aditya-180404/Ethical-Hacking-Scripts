Here are some fun and visually entertaining commands/tools you can install on Kali Linux to make your terminal look alive while still being lightweight.

---

# Terminal Fun Commands

## 1. `sl` — Steam Locomotive

Mistype `ls` once and a train appears.

### Install

```bash
sudo apt install sl
```

### Run

```bash
sl
```

Extra modes:

```bash
sl -a
sl -l
sl -F
```

---

## 2. `cowsay`

Classic talking cow.

### Install

```bash
sudo apt install cowsay
```

### Run

```bash
cowsay "Hello hacker"
```

Random cow:

```bash
cowsay -r "Kali Linux"
```

---

## 3. `lolcat`

Rainbow colored text.

### Install

```bash
sudo apt install lolcat
```

### Example

```bash
echo "Access Granted" | lolcat
```

Animated:

```bash
yes "KALI" | lolcat
```

---

## 4. `figlet`

Huge ASCII banners.

### Install

```bash
sudo apt install figlet
```

### Example

```bash
figlet KALI
```

Combine with lolcat:

```bash
figlet HACKER | lolcat
```

---

## 5. `toilet`

Like figlet but with better effects.

### Install

```bash
sudo apt install toilet
```

### Example

```bash
toilet -f future "KALI"
```

Rainbow:

```bash
toilet -f big -F gay "ROOT"
```

---

## 8. `neofetch`

Shows system info beautifully.

### Install

```bash
sudo apt install neofetch
```

### Run

```bash
neofetch
```

Auto-run on terminal open:

```bash
echo "neofetch" >> ~/.zshrc
```

---

## 9. `pokemon-colorscripts`

Displays Pokémon in terminal with colors.

### Install

```bash
git clone https://github.com/AbdBarho/pokemon-colorscripts.git
cd pokemon-colorscripts
sudo ./install.sh
```

### Run

```bash
pokemon-colorscripts -r
```

Specific Pokémon:

```bash
pokemon-colorscripts -n pikachu
```

---

## 10. `asciiquarium`

ASCII aquarium in terminal.

### Install

```bash
sudo apt install libcurses-perl
cpan Term::Animation
wget https://robobunny.com/projects/asciiquarium/asciiquarium
chmod +x asciiquarium
sudo mv asciiquarium /usr/local/bin
```

### Run

```bash
asciiquarium
```

---

# Best Combined Setup

Add this to your `~/.zshrc` for a cool startup:

```bash
pokemon-colorscripts -r
figlet KALI | lolcat
```

Or:

```bash
neofetch
```

# Minimal “Hacker” Combo Recommendation

Install these together:

```bash
sudo apt install sl cowsay lolcat figlet toilet cmatrix hollywood neofetch btop pipes.sh
```

Then add:

```bash
neofetch
pokemon-colorscripts -r
```

to your `~/.zshrc` for a stylish startup every terminal launch.
