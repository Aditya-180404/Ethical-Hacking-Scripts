It is an open source tool that allows you to find usernames across many social media platforms. It is written in Python and can be used to quickly gather information about a person or organization by searching for their username on various social media sites. Sherlock is a powerful tool for OSINT (Open Source Intelligence) gathering and can be used for various purposes, including cybersecurity, digital forensics, and social media analysis.

# Commands

1. sherlock [username] -> This command will search for the specified username across all supported social media platforms.
2. sherlock [phone_number] -> This command will search for the specified phone number across all supported social media platforms.
3. sherlock [email] -> This command will search for the specified email address across all supportedsocial media platforms.
4. sherlock [Username] --site thread -> This command will search for the specified username on the specified social media platform (e.g., Twitter, Facebook, Instagram).
5. sherlock [Username] --site all -> This command will search for the specified username
6. sherlock [Username]{?} -> This command will find the simillar username like if the username is Aditya then it will also search for Aditya1, Aditya_ etc. It will find the simillar username and show the result.
7. sherlock [Username1] [Username2] -> This command will search for both specified usernames across all supported social media platforms.
8. sherlock [Username] --proxy 192.168.1.1:8080 -> This command will use the specified proxy server for the search.
9. sherlock [Username] --dump-response ->  This command do http Response searching.It means it returns the headers of all the websites where the user name is found.
10. sherlock [Username] --time 1 -> this cvommand shows the results after 1 call or 1 knock.
11. sherlock [Username] --print-all -> This command will print all the results, including those that are not found.
12. sherlock [Username] --print-found -> This command will print only the results that are found.
13. sherlock [Username] --site-thread --browse -> This command will search for the specified username on the specified social media platform and open the found profiles in a web browser.
14. Sherlock [Username] -o res.txt -> This command will save the results of the search to a file named res.txt.




# usage: 

    sherlock [-h] [--version] [--verbose] [--folderoutput FOLDEROUTPUT] [--output OUTPUT] [--tor] [--unique-tor] [--csv] [--xlsx] [--site SITE_NAME] [--proxy PROXY_URL]
                [--dump-response] [--json JSON_FILE] [--timeout TIMEOUT] [--print-all] [--print-found] [--no-color] [--browse] [--local] [--remote] [--nsfw] [--no-txt]
                [--ignore-exclusions]
                USERNAMES [USERNAMES ...]

Sherlock: Find Usernames Across Social Networks (Version 0.16.0)

positional arguments:
  USERNAMES             One or more usernames to check with social networks. Check similar usernames using {?} (replace to '_', '-', '.').

options:
  -h, --help            show this help message and exit
  --version             Display version information and dependencies.
  --verbose, -v, -d, --debug
                        Display extra debugging information and metrics.
  --folderoutput, -fo FOLDEROUTPUT
                        If using multiple usernames, the output of the results will be saved to this folder.
  --output, -o OUTPUT   If using single username, the output of the result will be saved to this file.
  --tor, -t             Make requests over Tor; increases runtime; requires Tor to be installed and in system path.
  --unique-tor, -u      Make requests over Tor with new Tor circuit after each request; increases runtime; requires Tor to be installed and in system path.
  --csv                 Create Comma-Separated Values (CSV) File.
  --xlsx                Create the standard file for the modern Microsoft Excel spreadsheet (xlsx).
  --site SITE_NAME      Limit analysis to just the listed sites. Add multiple options to specify more than one site.
  --proxy, -p PROXY_URL
                        Make requests over a proxy. e.g. socks5://127.0.0.1:1080
  --dump-response       Dump the HTTP response to stdout for targeted debugging.
  --json, -j JSON_FILE  Load data from a JSON file or an online, valid, JSON file. Upstream PR numbers also accepted.
  --timeout TIMEOUT     Time (in seconds) to wait for response to requests (Default: 60)
  --print-all           Output sites where the username was not found.
  --print-found         Output sites where the username was found (also if exported as file).
  --no-color            Don't color terminal output
  --browse, -b          Browse to all results on default browser.
  --local, -l           Use the local data.json file.
  --remote              Fetch data.json from GitHub instead of the local file.
  --nsfw                Include checking of NSFW sites from default list.
  --no-txt              Disable creation of a txt file
  --ignore-exclusions   Ignore upstream exclusions (may return more false positives)
