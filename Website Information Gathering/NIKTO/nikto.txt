Nikto is a web-vulnarebility  scanning tool.

# Commands

1. nikto -h
2. nikto -dbcheck --> used to check database status.
3. nikto --host ip --> used for host scanning.
4. nikto -h flipkart.com --ssl --> This command checks the ssl status of the website.
5. nikto -h ip -p 80 --> specific port scanning of the target.
6. nikto -h ip -Cgidirs all --> finds cgi or hidden directories.
7. nikto -h ip -Display 1 -->  this scan show redirects.
8. nikto -h ip -Display -v --> verbosity scan.
9. nikto -h ip -maxtime 1 --> It is a ttl scan and in this case only one time the target will be knocked.
10 nikto -h ip -nolookup --> only scans the name server.
11. nikto -h ip no404 --> Disables nikto attempting to guess a 404 page.
12. nikto -h ip -Pause 10 --> scan the target for vulnarebility while pausing 10 seconds per request.
13. nikto -h ip -id admin --> finds vulnarebility in admin page.
14. nikto -h ip -id password --> finds vulnarebility in password.
15. nikto -h ip -Tuning --> for tuning
