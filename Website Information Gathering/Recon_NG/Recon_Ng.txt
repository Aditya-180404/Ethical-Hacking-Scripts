# Setup
1. Open Kali Terminal
2. recon-ng
3. workspaces create Adi  --> every time during work i have to create a new workspace
4. workspaces list  --> list of all workspaces
5. db insert domains --> after this insert the domain name
6. show domains  -->  to see the domain name
7. marketplace search  --> to see all modules list
8. marketplace install all  --> to install all modules
9. workspaces load Adi --> to load the workspace


# WhoIS Scan
1. modules load recon/domains-contacts/whois_pocs  --> load the whois module
2. run  --> run the module
3. back  --> it is required to run another scan



## Host Domain Scan
1. modules load recon/domains-hosts/bing_domain_web  --> to load the bing module
2. run  --> to run the module
3. back  --> to go back to the main menu


## Reverse Scan
1. modules load recon/hosts-hosts/reverse_resolve  --> it works only on hosts or ip addresses not on domains (like - https://uit.buruniv.ac.in/)
2. run  --> to run the module
3. back --> to return to the main menu


## Find subdomains/hosts
1. modules load recon/domains-hosts/certificate_transparency  --> it is used to find subdomains/hosts
2. run  --> to run the module
3. back  --> to return to the main menu

## DNS Resolution
1. modules load recon/domains-hosts/hackertarget  --> it is used to find the dns and ip address of the domain
2. run  --> to run the module
3. back  --> to return to the main menu


## Report Generate
1. modules load reporting  --> it is used to generate the report of the scan. Here we can generate the report in different formats like html, csv, json, xml etc.
2. modules load reporting/html  --> it is used to generate the report in html format
3. options set FILENAME /home/ghost/Documents/New.html  --> it is used to set the file name and path where the report will be saved
4. options set CREATOR ADi --> it is used to set the creator name in the report
5. Options set CUSTOMER Saturnx  --> it is used to set the customer name in the report
6. run  --> to run the module and generate the report
7. back  --> to return to the main menu
