1. It is an open source Web Intelligence gathering tool.
2. It is gui based like the NESSUS .
3. It is used to gather the information about the target website like IP address, location, hosting provider, traffic rank, email address of the owner, phone number of the owner and social media profiles of the owner.

# Commands
1. spiderfoot -l 127.0.0.1:5050  --> This command runs the spiderfoot on the local host and listens on port 5050.
2. spiderfoot -s target.com  --> This command starts a scan on the target website.


Open the browser -> paste the ip and port -> there put the scanning name -> paste the domain name  -> start scanning
