# Ethical Hacking Scripts

This repository contains quick reference notes for website information gathering using simple online tools.

## Contents

- [`Website Information Gathering/Information Gathering By FTP Search Engine.txt`](Website%20Information%20Gathering/Information%20Gathering%20By%20FTP%20Search%20Engine.txt) - Notes on using NAPALM FTP INDEXER to search for FTP servers.
- [`Website Information Gathering/netcraft.txt`](Website%20Information%20Gathering/netcraft.txt) - Notes on using netcraft.com to find site, hosting, SSL, and DNS information.
- [`Website Information Gathering/Ping Utility scan.txt`](Website%20Information%20Gathering/Ping%20Utility%20scan.txt) - Notes on using the ping command to determine the maximum fragment size a target website can accept.
- [`Website Information Gathering/shodan.txt`](Website%20Information%20Gathering/shodan.txt) - Notes on using Shodan.io to discover exposed devices and vulnerable servers.
- [`Website Information Gathering/Time To Leave Fragmented Scan.txt`](Website%20Information%20Gathering/Time%20To%20Leave%20Fragmented%20Scan.txt) - Notes on using the ping command to check the time interval (TTL) between packets.
- [`Website Information Gathering/website informer.txt`](Website%20Information%20Gathering/website%20informer.txt) - Notes on using website.informer.com to get an organized view of WhoIs data and traffic rank.
- [`Website Information Gathering/WhoIs.txt`](Website%20Information%20Gathering/WhoIs.txt) - Notes on how to use WHOIS lookup services to collect domain registration, registrar, and contact information.
- [`Website Information Gathering/Youtube Data Viewer.txt`](Website%20Information%20Gathering/Youtube%20Data%20Viewer.txt) - Notes on how to use YouTube Data Viewer to inspect public video metadata such as view counts, thumbnails, tags, and estimated revenue.

## Purpose

These notes are designed as a lightweight reference for reconnaissance tasks when researching domains or analyzing YouTube videos during ethical hacking or security assessment work.

## How to Use

1. Open the [`Website Information Gathering`](Website%20Information%20Gathering/) folder.
2. Browse through the available text files depending on the type of information you want to gather (e.g., DNS, FTP, domain registration, exposed services).
3. Follow the specific instructions provided within each file.

## Tools Mentioned

- `whois.com` and `website.informer.com` for gathering domain registration details.
- `YouTube Data Viewer` for analyzing public YouTube video information.
- `NAPALM FTP INDEXER` for finding FTP servers.
- `ping` utility for checking network packet fragmentation and TTL.
- `netcraft.com` for site, hosting, and SSL information.
- `Shodan.io` for finding exposed devices and sensitive information.

## Notes

- These are reference notes, not scripts.
- Always use these techniques responsibly and in compliance with applicable laws, terms of service, and ethical guidelines.
